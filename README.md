# 🎙 Система аудиоаналитики для компьютерного клуба (MVP)

![Python](https://img.shields.io/badge/Python-3.9+-3776AB?logo=python&logoColor=white)
![FastAPI](https://img.shields.io/badge/FastAPI-009688?logo=fastapi&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-6.0+-512BD4?logo=dotnet&logoColor=white)
![Vosk](https://img.shields.io/badge/Vosk-offline%20STT-orange)
![SQLite](https://img.shields.io/badge/SQLite-003B57?logo=sqlite&logoColor=white)

Программный комплекс для автоматического контроля качества работы администраторов компьютерного клуба.

Система записывает разговоры на стойке ресепшена, переводит речь в текст **без использования интернета** (офлайн-распознавание), анализирует тональность диалога, ищет стоп-слова и формирует рейтинг сотрудников в веб-панели управления.

> Проект разработан в рамках производственной практики.

## ✨ Возможности

- 🎤 Запись звука с микрофона на стойке ресепшена
- 📝 Офлайн-распознавание речи (Speech-to-Text) через Vosk
- 😊 Анализ тональности диалога
- 🚫 Поиск стоп-слов в речи администратора
- 🏆 Рейтинг сотрудников
- 📊 Веб-панель с аналитикой смен и прослушиванием оригинальной записи

## 🛠 Архитектура и стек технологий

Проект состоит из четырёх независимых модулей:

| Модуль | Технологии | Назначение |
|---|---|---|
| **Бэкенд** (серверная часть) | `Python 3.9+`, `FastAPI`, `SQLAlchemy`, `SQLite` | Обработка аудио, маршрутизация API, работа с БД |
| **ИИ-модуль** | `Vosk API` | Локальный перевод речи в текст (Speech-to-Text) |
| **Клиент** (десктоп) | `C#`, `.NET`, `NAudio` | Консольное приложение: запись звука с микрофона и отправка HTTP-запросов на сервер |
| **Фронтенд** (дашборд) | `HTML5`, `CSS3`, `JavaScript (Vanilla)` | Одностраничное приложение (SPA) для просмотра аналитики |

```text
┌──────────────────┐   HTTP    ┌───────────────────────┐        ┌──────────┐
│  C# клиент       │ ────────► │  FastAPI бэкенд       │ ◄────► │  SQLite  │
│  (NAudio, mic)   │           │  + Vosk (STT)         │        └──────────┘
└──────────────────┘           └───────────┬───────────┘
                                           │ REST API
                                           ▼
                                ┌───────────────────────┐
                                │  Дашборд (index.html) │
                                └───────────────────────┘
```

## ⚙️ Требования к окружению

Перед запуском убедитесь, что установлено:

- **Python** 3.9 или выше
- **.NET SDK** 6.0 или выше
- Подключённый и работающий **микрофон**
- Языковая модель **Vosk** — папка `model` с файлами `vosk-model-small-ru-0.22` должна лежать в корне проекта

## 🚀 Инструкция по запуску

Для старта нужно запустить серверную часть, открыть панель управления и запустить клиент для записи звука.

### Шаг 1. Запуск сервера (бэкенд)

1. Откройте терминал в корневой папке проекта.
2. *(Опционально)* Создайте и активируйте виртуальное окружение.
3. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустите локальный сервер:

   ```bash
   uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload
   ```

### Шаг 2. Запуск панели управления (фронтенд)

Панель не требует сборки и отдельного веб-сервера.

1. Найдите файл `index.html` в корне проекта.
2. Откройте его в любом современном браузере (Chrome, Edge, Safari).
3. *(Опционально)* Если база данных пуста, заполните её тестовыми данными для презентации — в новом терминале выполните:

   ```bash
   python seed_data.py
   ```

### Шаг 3. Запуск C#-клиента (запись звука)

1. Откройте **второй терминал** и перейдите в папку C#-проекта (где лежит файл `.csproj`).
2. Восстановите зависимости (NAudio):

   ```bash
   dotnet restore
   ```

3. Запустите приложение:

   ```bash
   dotnet run
   ```

## 🎮 Как использовать систему (демонстрация)

1. Убедитесь, что сервер (`uvicorn`) работает.
2. В консоли C#-клиента нажмите **Enter**, чтобы начать смену и включить микрофон.
3. Произнесите тестовую фразу, например: *«Здравствуйте, добро пожаловать в наш клуб»*.
4. Нажмите **Enter** ещё раз, чтобы остановить запись. Файл автоматически отправится на сервер.
5. Перейдите в браузер с открытым `index.html` и обновите страницу.
6. В таблице **«Аналитика смен»** появится новая запись с расшифрованным текстом, оценкой тональности и плеером для прослушивания оригинала.
